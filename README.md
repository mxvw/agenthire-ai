# AgentHire Pro

Build the complete AgentHire AI production-ready SaaS recruitment platform described by the user. Use Next.js 16 App Router, TypeScript, Tailwind CSS v4, Shadcn UI, Supabase-ready architecture, Framer Motion, and Lucide. Deliver premium responsive dark-mode UI inspired by Linear/Stripe/Vercel/Notion, full landing page plus jobs/search/detail, resume dashboard, applications, company dashboard, admin analytics, auth flows including Google-ready support, schema/integration setup, resume analysis and job match flows, AI career assistant, saved jobs/favorites/settings, English/Uzbek/Russian support, SEO metadata/OG/structured data/sitemap/robots, Vercel env configuration, and fully functional/exposed WebMCP tools: search_jobs, match_resume, apply_job, schedule_interview, get_application_status. Use clean scalable architecture and realistic seeded/demo data where credentials/integrations need later configuration.
